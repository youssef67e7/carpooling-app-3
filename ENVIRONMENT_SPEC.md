## Environment Validation

On startup, the app must validate that all required env vars are present:

```javascript
// config/env.js — startup validation
const REQUIRED_ENV = [
  'MONGODB_URI',
  'JWT_SECRET',
  'TWILIO_ACCOUNT_SID',
  'TWILIO_AUTH_TOKEN',
  'CLOUDINARY_CLOUD_NAME',
  'CLOUDINARY_API_KEY',
  'CLOUDINARY_API_SECRET',
];

const OPTIONAL_ENV = [
  'SENTRY_DSN',
  'ADMIN_IP_WHITELIST',
  'CORS_ORIGINS',
];

function validateEnv() {
  const missing = REQUIRED_ENV.filter(key => !process.env[key]);
  if (missing.length > 0) {
    throw new Error(`Missing required env vars: ${missing.join(', ')}`);
  }
}
```
