```
Flutter App
    │
    ▼ GoRouter (auth redirect)
    │
    ▼ Riverpod Providers (AuthState, RideState, etc.)
    │
    ▼ Dio ApiClient (JWT interceptor → auto-refresh on 401)
    │
    ▼ HTTP REST (JSON)
    │
Express Server
    ├── Middleware Pipeline (helmet → cors → logger → auth → validate)
    ├── Route Handler
    │   ├── Service Layer (business logic)
    │   └── ODM Layer (MongoQuery + native helpers)
    └── MongoDB (native driver)
```

### 5.2 ODM Polymorphic Query Strategy

```
MongoQuery.exec()
  ├── Simple find (no populate) → nativeFind()
  │     (projection + limit + skip passed to MongoDB)
  ├── findById + select + lean → nativeFindOne()
  ├── Requires populate → loadCollectionDocs()
  │     (in-memory join fallback)
  └── update/delete ops → nativeUpdateOne, nativeDeleteOne, etc.
```

## 8. Auth Flow

```
1. Login/Register
   └── POST /auth/google | /auth/login | /auth/register
   └── Returns { accessToken, refreshToken, user }
   └── accessToken → in-memory (Riverpod)
   └── refreshToken → shared_preferences

2. Authenticated request
   └── Dio interceptor → Authorization: Bearer <accessToken>

3. Token refresh (401 → auto)
   └── POST /auth/refresh { refreshToken }
   └── Old token hashed & stored (SHA-256)
   └── Returns new { accessToken, refreshToken }
   └── Retry original request

4. Logout
   └── POST /auth/logout → invalidates refresh token
   └── Clear tokens from memory + storage
```

## 11. Concurrency & Race-Condition Fixes

| Bug | Root Cause | Fix | Atomic Mechanism |
|-----|-----------|-----|-----------------|
| Ride creation TOCTOU | Two requests both pass `findOne` check | Unique partial index `passenger_id_unique_active` | MongoDB index constraint |
| Wallet set-default race | Concurrent `clear+set` creates two defaults | Unique partial index `user_id_unique_default` | MongoDB index constraint |
| Promotion over-redemption | `read→check→write` gap | `findOneAndUpdate` with `$expr` guard | MongoDB document-level atomicity |
| Referral duplicate apply | No uniqueness on referredUsers array | `findOneAndUpdate` with `$ne` filter | MongoDB document-level atomicity |
| Wallet account 409 missing | POST `/accounts` had no E11000 handler | try/catch returning 409 | MongoDB index constraint |

## 12. Key Patterns

### Field Mapping (camelCase ↔ snake_case)

- Client sends/receives camelCase JSON
- `fieldMap.js` maintains bidirectional mapping
- `nativeQuery.convertFilterKeys()` auto-maps filter keys
- ODM converts on read/write transparently

### Idempotency

- POST `/wallet/deposit` accepts `idempotencyKey`
- Unique sparse index on `transactions.idempotencyKey`
- Same key → return existing transaction (no duplicate charge)

### Token Security

- JWT access tokens (short-lived)
- Refresh tokens hashed with SHA-256 before DB storage
- Rotation: each refresh invalidates previous token
- TTL index auto-clears expired tokens (7 days)
